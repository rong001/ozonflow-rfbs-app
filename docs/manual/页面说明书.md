# 页面说明书

本说明书覆盖 OzonFlow 的 **全部 26 个页面**（视图 ID 来自 `index.html` 中 `.nav-item[data-view]`），按侧栏 6 个分组排序。每页包含：截图、页面用途、入口路径、页面区域说明、数据来源、适用角色、关联页面。截图均为 1440 宽整页实拍（「旺季履约突击」经营场景、广州数码专营店、老板角色）。

**数据来源标记说明**

| 标记 | 含义 |
|---|---|
| 【连接器】 | 免密钥模式：OzonFlow 连接器扩展在已登录的卖家后台读取，或卖家后台导出报表导入 |
| 【公开接口】 | 经扩展调用的公开数据：Ozon / WB 前台同款价格、菜鸟国际轨迹查询 |
| 【本地计算】 | 浏览器内根据业务数据集与共享费率计算（利润、风险分、建议等），存于 localStorage |
| 【待接 API】 | 需要 Ozon Seller API Api-Key（经 `server/ozon-proxy.js`）或第三方授权后才能自动读写 |

**全局元素（所有页面通用）**

- **侧栏**：6 个分组（工作台 / 订单履约 / 商品增长 / 客服售后 / 财务风控 / 自动化与集成），悬停展开，可固定；分组图标角标为组内待办合计；底部「开店引导」「使用手册」「固定侧栏」。
- **顶栏**：面包屑 + 页面标题；命令面板入口（Ctrl/⌘K）；经营场景；店铺切换；角色切换；订单同步状态；通知铃铛；使用手册「?」；重置当前场景「↻」；角色头像。
- **提示消息**：每次操作后在右上角显示约 3 秒（✓ 成功 / ℹ 信息）。
- **说明图标 ⓘ**：卡片标题旁的 ⓘ 悬停显示该卡片的口径说明。

| 分组 | 页面（视图 ID） |
|---|---|
| 工作台 | 经营总览 dashboard · AI 指令台 copilot · 审批中心 approvals · 经营周报 weekly |
| 订单履约 | 订单履约 orders · 时效物流 sla · 物流与库存 logistics · 供应链库存 supply · 自动化规则 rules |
| 商品增长 | 智能选品 selection · 市场选品 market · 刊登上架 listing · 素材工坊 studio · 内容合规 content · 价格竞争 compete · 推广活动 promo |
| 客服售后 | 客服评价 cs · 客服收件箱 inbox · 退货异常 returns |
| 财务风控 | 利润定价 profit · 财务对账 finance · 店铺健康 health |
| 自动化与集成 | 自动化 Agent agents · 数据连接 connect · 平台集成 platform · 能力矩阵 capability |

# 一、工作台

## 1. 经营总览（dashboard）

![经营总览](img/p-dashboard.png)

- **页面用途**：每天开工的第一屏，汇总当前店铺今日关键数字、按风险排序的待办和趋势。
- **入口路径**：侧栏「工作台 → 经营总览」；打开系统默认进入；命令面板输入「总览」。
- **页面区域说明**
  - **焦点区（Hero）**：日期 · 星期 · 店铺；一句话今日重点（如「今天先处理 3 单临近超时，4 项待审批」）；「Agent 今日已处理 N 项」「N/13 个已启用」；按钮「AI 指令台」（跳转 AI 指令台）、「一键跑全部 Agent」（按级联顺序运行 13 个 Agent，见 agents 页）。
  - **开店进度卡**：仅在开店向导未完成或刚完成时显示，4 项（绑定店铺 / 选择 rFBS / 默认物流 / 导入商品）完成状态与「继续引导」。
  - **KPI 卡（5 张）**：今日订单（当前店铺）；待发货（副标题：含待采购 N）；超时风险（距截单 < 6h，红色）；预估毛利 ₽（已扣退货拨备）；差评 / 退货（差评 N · 退货 N）。
  - **今日待办**：右上角「N 项」。每行：色点（红 = 高风险、橙 = 警示、紫 = 待采、蓝 = 信息）、标题、说明、按钮。条目包括：高风险动作待审批 → 去审批（审批中心）；超时备货 → 去处理（订单 · 超时风险）；待审单 → 去审单（订单 · 待审核）；缺货待采 → 去采购（订单 · 待采购）；差评待回 → 去回复（客服评价）；退货异常 → 去处理（退货 · 待处理）；物流轨迹异常 → 去查看（订单 · 已发货）；1★ 待升级 → 去客服；资金异常提醒 → 看周报；刊登待处理 → 去刊登。
  - **近 7 日订单趋势**：柱状图（订单量 / 峰值日高亮），右上角为当前店铺标签。
  - **今日热销 TOP 5**：列 = 商品（俄文名 + 中文名）/ Ozon SKU / 今日销量 / 售价 ₽ / 预估毛利（%）/ 库存（低库存标红）；「查看选品 →」跳智能选品。
- **数据来源**：订单、商品【连接器】；KPI、毛利、待办排序【本地计算】。
- **适用角色**：老板、运营、仓管、客服、财务。
- **关联页面**：订单履约、审批中心、客服评价、退货异常、刊登上架、智能选品、自动化 Agent、AI 指令台。

## 2. AI 指令台（copilot）

![AI 指令台](img/p-copilot.png)

- **页面用途**：用一句中文口语下达经营指令，系统先给出执行计划（影响范围与风险），确认后执行或送审批。
- **入口路径**：侧栏「工作台 → AI 指令台」；经营总览「AI 指令台」按钮；命令面板最后一项「让 AI 执行：…」。
- **页面区域说明**
  - **输入卡「想让系统做什么？」**：ⓘ 说明「先预览影响范围，确认后才执行。改价超 10%、退款 ≥ 2000₽、采购 ≥ ¥1000、取消订单都会进审批中心」；输入框（回车或「解析指令」）；示例标签 7 个 + 「更多 15 条」（共 22 条：把毛利低于 20% 的商品提价 8% / 处理所有超时订单 / 回复所有差评 / 补货低于安全库存的 SKU / 跑一遍所有 Agent / 查询今天待发货订单 / 检查物流轨迹异常 / 生成本周周报 / 切换到深圳配件馆 / 打开审批中心 / 暂停所有亏损广告 / 检查证书到期和风险词 / 对一下本店回款差异 / 看看店铺健康和错误指数 / 回传所有运单号 / 回复买家消息 / 生成今日简报 / 同步店铺数据 / 采集同款价格 / 查物流轨迹 / 推送简报到群 / 库存快没了怎么办）。
  - **执行计划卡**（解析后出现）：识别意图、影响对象数量、风险标签（低风险 / 需审批）、受影响对象明细表（列随意图变化，如 商品 / SKU / 本地库存 / 安全库存）；按钮「确认执行」「取消」。
  - **指令记录**：时间、指令、结果；非只读指令同时写入审计日志。
- **数据来源**：意图解析为规则引擎 + 浏览器内语义模型 bge-small-zh（transformers.js，首次加载约 24MB，无需大模型 Key）【本地计算】；执行动作作用于业务数据【本地计算】，写回平台【待接 API】。
- **适用角色**：老板、运营、仓管、客服、财务（执行受角色权限约束）。
- **关联页面**：审批中心、订单履约、自动化 Agent、命令面板。

## 3. 审批中心（approvals）

![审批中心](img/p-approvals.png)

- **页面用途**：人在环把关高风险动作，老板通过即执行、驳回留痕，所有动作可审计。
- **入口路径**：侧栏「工作台 → 审批中心」（角标为待审批数）；经营总览待办「去审批」。
- **页面区域说明**
  - **KPI**：待审批（高风险 N）/ 已通过（通过即执行）/ 已驳回（留痕可追溯）/ 审计记录（人工 + Agent）。
  - **审批列表**：页签「待审批 N」「已处理 N」；右侧阈值说明「改价 > 10% · 退款 ≥ 2000₽ · 采购 ≥ ¥1000 · 取消订单」与「批量通过」。列：风险（中 / 高）/ 类型（改价、退款、取消订单、采购、暂停广告、活动报名、申诉、侵权投诉）/ 事项 / 变更前 → 后 / 原因 / 发起方（Agent 或角色）/ 时间 / 操作（通过、驳回）。非老板角色按钮置灰并提示切到老板。
  - **操作审计日志**：最近 N 条 · 当前店铺；列 时间 / 操作人 / 动作 / 对象 / 结果。
- **数据来源**：审批项由 Agent、AI 指令台、各业务页按阈值生成【本地计算】；执行后写回平台【待接 API】。
- **适用角色**：老板（审批）、运营、财务（查看）。
- **关联页面**：价格竞争、推广活动、退货异常、供应链库存、内容合规、店铺健康、自动化 Agent、财务对账。

## 4. 经营周报（weekly）

![经营周报](img/p-weekly.png)

- **页面用途**：按店铺、按 SKU 回顾销售、净利、超时率与退货率。
- **入口路径**：侧栏「工作台 → 经营周报」；总览待办「看周报」。
- **页面区域说明**
  - **操作栏**：「刷新数据」（重新计算并提示生成时间）、「导出周报」（导出当前店铺周报，本地导出提示）。
  - **KPI**：本周销售额（₽ · 全店合计）/ 预估净利 / 平均超时率（rFBS 时效）/ 平均退货率（含取消 / 索赔）。
  - **分店铺汇总**：店铺（当前店标注）/ 订单 / 已发货 / 销售额 ₽ / 净利 ₽ / 毛利率 / 超时率 / 退货率。
  - **当前店铺 · SKU 明细**：SKU / 商品 / 单量 / 销售额 ₽ / 净利 ₽ / 毛利率。
- **数据来源**：订单与退货【连接器】；汇总口径【本地计算】。
- **适用角色**：老板、运营、财务。
- **关联页面**：自动化 Agent（周报汇报 Agent）、平台集成（每日简报）、数据连接（群推送）。

# 二、订单履约

## 5. 订单履约（orders）

![订单履约](img/p-orders.png)

- **页面用途**：rFBS 订单从审核、采购、面单到发货的主工作台。
- **入口路径**：侧栏「订单履约 → 订单履约」（角标为待处理数）；三级菜单 待审核 / 待采购 / 待发货 / 超时风险；总览待办。
- **页面区域说明**
  - **筛选签**：全部 / 待审核 / 待采购 / 待发货 / 已发货 / 超时风险（剩余时效 ≤ 6h 且未发货），均带数量。
  - **搜索框**：按订单号 / 买家 / SKU 即时过滤。
  - **按钮**：「同步订单」（在当前业务数据集中按在售商品生成新订单；真实订单经数据连接导入）；「一键审单」（对待审核订单执行审单规则）；「批量申请面单」（为待发货 / 待采购且无运单号的订单取号）。
  - **表格列**：订单号 / 商品（缩略图、名称、SKU）/ 买家 / 城市 / 金额 ₽ / 物流（渠道或「未分配」）/ 自动化（已审单、已匹配物流、已取号、已采购标签）/ 状态 / 剩余时效（≤6h 红色）/ 操作（审单、采购完成、面单、发货，按状态显示）。
  - **订单详情抽屉**（点击行）：商品信息与状态；买家、收货城市、订单金额、采购成本（¥ ≈ ₽）、预估毛利（₽ 与 %）、物流渠道、运单号、剩余时效；自动化轨迹时间线；快捷操作（手动审单 / 匹配物流 / 采购完成 / 申请面单 / 确认发货）。
- **数据来源**：订单【连接器】（扩展捕获或报表导入）；审单、物流匹配、取号规则【本地计算】；发货、取号写回 Ozon【待接 API】（`/v4/posting/fbs/ship`、`/v2/posting/fbs/package-label`），当前需在卖家后台人工完成。
- **适用角色**：老板、运营、仓管、客服（只读）。
- **关联页面**：时效物流、物流与库存、自动化规则、店铺健康、数据连接、自动化 Agent。

## 6. 时效物流（sla）

![时效物流](img/p-sla.png)

- **页面用途**：围绕 rFBS 截单时效：休息日影响、运单号回传、渠道运价比较、报关一致性、IML 退货仓处置。
- **入口路径**：侧栏「订单履约 → 时效物流」（角标为未回传运单数）。
- **页面区域说明**
  - **KPI**：休息日影响截单（截单期内有仓库休息日）/ 运单号未回传（已发货但 Ozon 后台无轨迹）/ 可省物流费 ₽（改走最便宜且满足时效的渠道）/ 报关资料异常（HS 编码、品名或申报价不一致）。
  - **仓库休息日对截单期影响**：输入框「休息日（MM-DD，逗号分隔）」「每周休息」；表格 订单 / 商品 / 剩余时效 / 截单时间 / 期间休息日 / 建议（休息日前发出 / 安排值班）。ⓘ 提醒在 Ozon 后台同步仓库日程。
  - **rFBS 状态与运单号回传**：「全部回传」；列 订单 / 商品 / 物流 / 运单号 / Ozon 状态（未回传、已回传 · 运输中）/ 操作「回传运单号」。
  - **渠道规则匹配与运价比较**：订单 / 重量 / 当前渠道 / 云途 / 燕文 / OGL / 本地仓（运费与时效）/ 建议 / 操作「改用」。运费 = 每公斤单价 × 重量 + 挂号费 ¥12。
  - **报关资料一致性校验**：订单 / HS 编码 / 申报价 / 订单价 / 问题 / 「一键修正」（按订单价 80% 校准、补 HS 编码与英文品名）。
  - **IML 退货仓处置决策**：退货单 / 商品 / 金额 / 退回国内成本 / 本地二次销售 / 建议 / 「按建议处置」。
- **数据来源**：订单与运单【连接器】；休息日、运价、报关校验【本地计算】；运单号回传【待接 API】（`/v2/fbs/posting/tracking-number/set`），当前需在卖家后台手动填写。
- **适用角色**：老板、运营、仓管。
- **关联页面**：订单履约、店铺健康、退货异常、物流与库存。

## 7. 物流与库存（logistics）

![物流与库存](img/p-logistics.png)

- **页面用途**：管理物流渠道连接与本地仓 ↔ Ozon 在售库存同步、补货。
- **入口路径**：侧栏「订单履约 → 物流与库存」。
- **页面区域说明**
  - **物流渠道**：卡片 云途专线·俄线 / 燕文物流·经济 / Ozon OGL 官方 / 递四方·标准 / CNE 国际快递 / 义乌集货仓·自提；每张显示连接状态、均价（¥/kg 或按平台计费）、时效、今日票数；未连接的有「连接」按钮。
  - **仓库库存同步 · 当前店铺**：「上次同步：…」「立即同步」；列 SKU / 货号 / 商品 / 本地仓 / Ozon 在售库存 / 安全库存 / 同步状态（正常、低库存）/ 操作「补货 +50」。
- **数据来源**：库存与商品【连接器】；渠道参数与低库存判断【本地计算】；库存回写【待接 API】（`/v2/products/stocks`），物流商面单接口需各物流商账号【待接 API】。
- **适用角色**：老板、运营、仓管。
- **关联页面**：订单履约、供应链库存、自动化规则、开店向导（默认物流）。

## 8. 供应链库存（supply）

![供应链库存](img/p-supply.png)

- **页面用途**：多店共享库存防超卖、SKU 级 rFBS / FBO / FBP 决策、海外仓补货与滞销清理。
- **入口路径**：侧栏「订单履约 → 供应链库存」。
- **页面区域说明**
  - **KPI**：超卖风险 SKU / 建议转 FBO/FBP / 海外仓滞销（库龄或周转 > 90 天）/ 海外仓 SKU（出库申请时限 60 天）。
  - **多店共享库存防超卖**：「全部重分配」；列 SKU / 商品 / 实际库存 / 各店挂出 / 合计挂出 / 状态 / 操作。按近 7 天销量比例分配并预留 10%。
  - **SKU 级履约模式决策**：商品 / 日销 / rFBS 单件物流 / FBO 单件物流 + 仓储 / 单件节省 / 备货资金（45 天）/ 建议（FBO、FBP 合作仓、rFBS）。
  - **海外仓补货计划与滞销清理**：商品 / 海外仓库存 / 库龄 / 日销 / 周转天数 / 建议 / 操作「生成补货单」（金额 ≥ ¥1000 进审批）、「生成清仓方案」。
- **数据来源**：库存、销量【连接器】；分配与决策【本地计算】；海外仓出库申请【待接 API】。
- **适用角色**：老板、运营、仓管。
- **关联页面**：物流与库存、审批中心、推广活动（清仓报名）。

## 9. 自动化规则（rules）

![自动化规则](img/p-rules.png)

- **页面用途**：配置并执行 IF / THEN 履约规则。
- **入口路径**：侧栏「订单履约 → 自动化规则」。
- **页面区域说明**

  - **回款日历与资金预测**：日期 / 来源 / 金额 ₽ / 折合 ¥（每月 15 日与月末两次回款估算）。

- **适用角色**：老板、运营、财务。
- **关联页面**：订单履约、时效物流、审批中心、平台集成（规则知识库）。

## 24. 数据连接（connect）

![数据连接](img/p-connect.png)

- **入口路径**：侧栏「自动化与集成 → 数据连接」；命令面板「同步店铺数据」。
- **页面区域说明**
